A quick broadcast to all users — for things like scheduled maintenance or a heads-up, separate from version release notes below.
🔔 Send User Notification ADMIN
One persistent notification per user. If a user is offline, it appears when they next open the app. After they open and mark it read, it will not appear again.
📢 Push App Update Notice ADMIN
Notify all users of a new version. They'll see a banner next time they open the app.
🗄️ Manage Database ADMIN
Export a full backup of every table the app can read. Large accounts may take a few seconds.
If your Supabase Row-Level Security policies restrict reads to each user's own rows, this export will only contain what the admin account itself can see — grant the admin account broader read access in Supabase if you need a truly complete backup.
